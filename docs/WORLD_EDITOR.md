# Visages Forge

Forge — отдельный Win32-редактор авторских карт. Он использует общие с игрой каталоги и рендер мира,
но имеет собственный документ и историю отмены. По умолчанию открываются «Солнечные холмы».
Диагностическая `demo.rtsmap` сохраняется для проверок механик.

## Слои карты

| Слой | Данные и влияние |
|---|---|
| Местность | Высота, поверхность, рампы и базовый материал; определяет проходимость |
| Покраска | Мазки материала с радиусом, прозрачностью и мягким краем; только изображение |
| Декор | Дробная позиция, масштаб и поворот; не меняет движение и обзор |
| Игровое окружение | Стабильный ID, прочность, клеточный фундамент, маска коллизии и перекрытие обзора |
| Ресурсы и юниты | Запасы месторождений, стартовые и дополнительные сущности |

Логические квадратные клетки отображаются ромбами 2:1. Новые карты имеют прямоугольную видимую границу
и размеры, кратные 32. Обрезанные клетки на краях неигровые: нельзя поставить часть здания или выйти
туда кругом юнита. Координаты симуляции остаются логическими; геометрия описана в [ARCHITECTURE.md](ARCHITECTURE.md).

Для рампы нужен перепад ровно на один уровень. «Рампа ×3» ставится на нижнем краю и направляется вверх;
подготовьте три свободные параллельные полосы. На берегу оставляйте сухую нижнюю полосу для рампы.
Мелководье и глубина различаются поверхностью, а не обязательным перепадом высоты.

Редактор отклоняет несовместимое размещение игровых объектов и изменение высоты под занятой клеткой.
Подложку и покраску можно менять под объектами. Широкие рампы и проходы проверяйте юнитами в тестовом бою.

## Управление

| Действие | Клавиша / мышь |
|---|---|
| Рисование / размещение выбранного элемента | ЛКМ, для кисти — с движением |
| Удаление | Инструмент «Удалить» / Delete, затем ЛКМ у основания объекта |
| Перемещение старта | «Точка старта», выбрать маркер и новое место |
| Радиус кисти | [ / ] или кнопки − / + |
| Плотность и параметры инструмента | Соответствующие − / + справа |
| Поворот декора / направление рампы | R |
| Камера | WASD, стрелки, средняя кнопка |
| Масштаб | Колесо над картой |
| К стартовой базе | Home |
| Сетка и маски объектов | K, английская раскладка |
| Отмена / повтор | Ctrl+Z / Ctrl+Y, до 32 операций |
| Сохранить / сохранить как | Ctrl+S / Ctrl+Shift+S |
| Открыть / создать | Ctrl+O / Ctrl+N |
| Перечитать каталоги и изображения | F5 |
| Тестовый бой / выход из него | F9 / F10 |
| Завершить мазок | Esc или ПКМ |

Отмена действует на целый мазок. Фильтр `group` в палитре объединяет ассеты по наборам;
`All assets` показывает все записи. Дополнительному юниту можно назначить владельца,
но это не добавляет новых игровых слотов: авторская карта имеет один слот игрока.

## Тестовый бой

F9 сохраняет временную авторскую копию, включая несохранённые изменения, и запускает соседний
`Visages of War.exe` с `--forge-test`. Forge остаётся запущенным. F10 завершает тест и возвращает
редактор; документ и история отмены сохраняются. Добыча, смерти и стройка в игре документ не меняют.

Оба exe должны находиться рядом. Временные карты лежат в `%LOCALAPPDATA%/RTS/forge/previews/`
и удаляются после теста. Оба приложения принимают `--map "путь к карте.rtsmap"`:
Forge открывает документ, игра запускает бой. Поиск ресурсов не зависит от рабочей папки.

## Формат и сохранение

`.rtsmap` — UTF-8 JSON текущей версии без миграций. Примеры находятся в [assets/maps](../assets/maps).
Документ хранит авторскую местность, мазки, ID и трансформации объектов, начальное здоровье,
старты и дополнительные сущности, ресурсные запасы. Туман, текущие приказы, очереди и изменяемое
состояние матча в него не попадают; это не сохранение игры.

`layoutSize` задаёт прямоугольную игровую область, `size` — массив клеток с запасом для обрезки.
Не заменяйте одно другим при внешней генерации. Для W×H сторона массива равна W/2+H и не превышает 512.
Значения размеров и позиционные ограничения проверяются загрузчиком.

По умолчанию карты сохраняются в `%LOCALAPPDATA%/RTS/maps/`. Запись выполняется через соседний временный
файл с заменой основного после успешного завершения. Поддерживаются Unicode и пробелы в пути.
Изображения не встраиваются: при переносе карты нужны используемые каталоги и PNG в целевой установке.

## Расширение каталога мира

[assets/world/catalog.json](../assets/world/catalog.json) подключает `materialFiles`, `objectFiles`,
`remainsFile` и `resourcesFile`. Пути считаются от `assets`. Добавляйте записи в тематические файлы,
сохраняя уникальные стабильные ID; отображаемое название можно менять независимо.

Материал задаёт `id`, `name`, `image`, `repeatCells`, необязательные `tint`, `group`, `isometric`.
Рисунок закреплён на поверхности мира и непрерывен через клетки. Один материал доступен как подложка
и кисть. Исходник остаётся видом сверху; проекция применяется движком. `isometric: false` позволяет
оставить рисунок без такого преобразования. Реальные настройки смотрите в каталогах материалов.

Объект задаёт `gameplay`, `kind`, `footprint`, `collision`, `health`, `blocksVision` и `sprite`.
`collision` описывает занятые части фундамента; размер картинки задаётся отдельно. Чистый декор
не становится препятствием из-за непрозрачного пикселя. Прочность ноль выключает игровой экземпляр,
но не удаляет его ID. После правки объектов пересобираются производные коллизия и обзор.

В `sprite` используются `image`, `source`, `size`, `anchor`, `pixelArt` и при необходимости `islandSeed`.
Рабочие примеры — в файлах, подключённых каталогом мира. Требования к графике и происхождению —
в [ASSETS.md](ASSETS.md), правила тумана и окружения — в [GAME_SYSTEMS.md](GAME_SYSTEMS.md).
