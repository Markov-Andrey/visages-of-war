# Visages of War — техническое руководство

RTS-прототип для Windows 10/11 x64: C++20, MSVC, CMake, Direct2D.
Игра и редактор Visages Forge — отдельные приложения с общими картами и каталогами.

## Запуск и возможности

Запускайте `Visages of War.lnk` или `Visages Forge.lnk` из корня проекта.
Поставка находится в `out/package/RTS/`; оба exe и папка `assets` должны оставаться вместе.
Обычная тестовая карта — `assets/maps/sunny-hills.rtsmap`.

Работают добыча кристаллов с доставкой, строительство и обучение, круговые столкновения
и групповые приказы, ближний и дальний бой, летающие юниты, опыт героя, высоты, вода,
обзор и цикл дня/ночи. Forge редактирует рельеф, покраску, окружение и стартовые позиции.

Это один локальный игровой слот. Кампании, сети, сохранения партии, инвентаря,
метапрогресса командира и полноценной системы эффектов ещё нет. Бой подключён между юнитами;
разрушение окружения доступно через API. У части сущностей временная графика.

## Управление игрой

| Действие | Управление |
|---|---|
| Выделение | ЛКМ; рамка; Shift добавляет/переключает |
| Свои юниты одного типа в камере | Двойной ЛКМ; Shift добавляет |
| Активный тип в группе | Tab / Shift+Tab |
| Один юнит из группы | ЛКМ по его иконке |
| Сохранить / выбрать контрольную группу | Ctrl+1…9/0 / 1…9/0 |
| Армия без рабочих / герой / свободный рабочий | F1 / F2 / F8 |
| Контекстный приказ | ПКМ по земле, врагу, ресурсу, стройке или ратуше |
| Движение / остановка / удержание | M → ЛКМ / S / H |
| Атака цели или движение с атакой | A → ЛКМ |
| Патруль между двумя точками | P → ЛКМ |
| Обстрел точки осадным оружием | T → ЛКМ |
| Добыча | G → ЛКМ по кристаллу |
| Стройка | Рабочий → B → H (ратуша), B (казарма), O (башня) → ЛКМ |
| Обучение | Ратуша: Q. Казарма: Q / E / T; также кнопки панели |
| Точка сбора | Здание → ПКМ по карте/миникарте либо R → ЛКМ |
| Отмена стройки или последнего заказа | Здание → X |
| Способности активного типа | Q / W / E, если доступны в панели |
| Камера | Край экрана, стрелки, средняя кнопка, миникарта |
| Масштаб / база | Колесо / Home |
| Сетка и пути | K; включены по умолчанию |
| Пауза / меню | Пробел / Esc |
| Отменить выбор цели или размещение | ПКМ или Esc |
| Консоль | Enter; `iseedeadpeople` открывает всю карту до конца матча |

Вражеские и нейтральные сущности доступны только для осмотра, если видны.
Движение относится ко всей группе, а специальные команды — к активному типу.
Камера работает на паузе; меню приостанавливает матч.
Управление Forge и сохранение карт: [WORLD_EDITOR.md](docs/WORLD_EDITOR.md).

## Сборка

Нужны Visual Studio 2022 или Build Tools с Desktop development with C++, Windows SDK
и C++ CMake tools. Минимальная версия CMake — 3.25.

```powershell
.\scripts\build.ps1 -Configuration Debug -Test
.\scripts\build.ps1 -Configuration Debug -Run
.\scripts\build.ps1 -Configuration Debug -RunForge
.\scripts\build.ps1 -Configuration Release -Test -Package
```

При ограничении ExecutionPolicy запускайте скрипт через
`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1` с нужными параметрами.
Перед пересборкой закройте заменяемые exe. MSVC runtime подключён статически.
Debug-приложения: `out/build/windows-x64/bin/Debug/`. Упаковка также обновляет ярлыки.

Ассеты ищутся относительно exe, пользовательские данные — в `%LOCALAPPDATA%/RTS/`:
`maps/`, `logs/`, временные карты Forge в `forge/previews/`. Рабочая папка процесса не важна.
В поставке это руководство называется `README.md`.

## Проверка и документация

Оба приложения принимают `--map "полный путь.rtsmap"`, `--verify-assets`,
`--snapshot "полный путь.png"` и `--smoke-test`. Игра также поддерживает
`--snapshot-grid`, `--snapshot-menu`, `--snapshot-title`.
CTest проверяет логику, ассеты, снимки, интерфейсы и переносимость путей.

- [ARCHITECTURE.md](docs/ARCHITECTURE.md) — модули, координаты, навигация и рендер.
- [GAME_SYSTEMS.md](docs/GAME_SYSTEMS.md) — правила матча и будущие системы.
- [DATA.md](docs/DATA.md) — определения сущностей, командиров и способностей.
- [COMBAT.md](docs/COMBAT.md) — атаки, снаряды и останки.
- [ASSETS.md](docs/ASSETS.md) — импорт графики, маски, свет и происхождение файлов.
- [UNIT_SPRITES.md](docs/UNIT_SPRITES.md) — контракт спрайтов юнита.
- [MAINTENANCE.md](docs/MAINTENANCE.md) — проверки и измерение производительности.

Точные цены, характеристики, размеры и состав паков находятся в `assets/data` и
`assets/world`; не переносите их копии в руководства.
