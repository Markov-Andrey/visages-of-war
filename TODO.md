Реализовать универсальную анимацию магического строительства для 2D изометрической RTS на основе готового PNG-спрайта здания с прозрачностью.

Механика

Строительство управляется параметром buildProgress от 0.0 до 1.0.

0% — Основание. На земле появляется светящийся золотой магический круг с церковной лампадкой в центре. Здание невидимо.

1–33% — Световой каркас. Из света формируются очертания здания: крыша, стены, окна, двери. Использовать Alpha Mask и Edge Detection (Sobel) по исходному спрайту. Здание полупрозрачное, золотисто-белое.

33–66% — Материализация. Снизу вверх проявляется исходная текстура здания через Height-based Dissolve с небольшим Noise. Граница проявления ярко светится.

66–100% — Завершение. Здание становится полностью непрозрачным, золотые контуры постепенно исчезают. Магический круг и лампадка растворяются.

Техническая реализация

Использовать готовый PNG здания, не создавать дополнительные кадры строительства.

Реализовать GPU-шейдер с Dissolve, Edge Glow, Alpha Mask, Noise, Emission.

Световые очертания должны соответствовать геометрии исходного спрайта.

Магический круг и лампадка — отдельные спрайты, расположенные на земле.

Поддержать прозрачность, мягкое свечение и аддитивное смешивание световых эффектов.

Не использовать 3D-модели.

Не менять исходную палитру готового здания.

Тим-колор не применять к магическому эффекту: только золотисто-белый свет.

Анимация должна быть плавной и полностью зависеть от buildProgress, без привязки к фиксированной длительности.

Требования

Система должна работать с любым зданием фракции, используя его исходный спрайт и общие эффекты строительства.

Предусмотреть возможность подключения дополнительной маски архитектурных контуров для более качественного результата.

Цель: визуально здание возникает из света, словно материализуется через церковный портал, а не строится обычным способом.

Изучи существующую архитектуру проекта и реализуй решение средствами используемого движка, без лишних зависимостей.
